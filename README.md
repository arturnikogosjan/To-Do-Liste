# To-Do-Liste

## Beschreibung
Dies ist eine einfache To-Do-Liste, mit der man Aufgaben hinzufügen und als erledigt markieren kann.

## Funktionen
- Aufgaben hinzufügen
- Aufgaben als erledigt markieren
- Aufgaben übersichtlich verwalten
